# Blue Team Toolkit

A curated collection of tools, scripts, playbooks, and cheat sheets designed for Blue Team defenders. This project is focused on practical, Security+-aligned capabilities for detecting, analyzing, and responding to security threats.

## Sections

### Tools
Scripts and utilities for:
- Hash verification (MD5, SHA256)
- IOC lookups (VirusTotal, AbuseIPDB)
- Log parsing (Apache, Windows Event Logs)
- PCAP analysis using Scapy and Zeek

### Scripts
- Windows and Linux triage
- Baseline auditing scripts
- System enumeration and quick assessment tools

### Cheat Sheets
- Ports and protocols
- Security log locations (Linux & Windows)
- SIEM queries (SPL, KQL, etc.)

### Playbooks
- Phishing response
- Malware outbreak containment
- Unauthorized access investigation

### Sample Data
- Sample PCAPs, logs, and mock alerts for demo and analysis
